|---|---|
| 파일 | `assets/village_school.png` (228×68), `assets/village_school_dark.png` (피해 때 꺼진 창만 담은 덧그림) |
| 만든 도구 | Leonardo.ai — 모델 Lucid Origin, **무료 플랜** (2026-11-16, 참가자가 직접 생성) |

## 저작권·이용 조건
- 타이틀 배경과 같음(`타이틀배경_AI이미지_출처.md`): Leonardo.ai 무료 플랜 생성물은 상업적 이용 허락을 받지만 소유권은 Leonardo에 있고 공개 이미지로 취급됨. 유료 플랜은 생성물 소유권이 사용자에게 있음.
- 참가신청서 AI 활용 내역에 "Leonardo.ai 무료 플랜 – 배경 일러스트·건물 그림"을 적는다.
