# 게임 속 건물 그림 출처 (AI 생성 이미지)

| 항목 | 내용 |
|---|---|
| 파일 | `assets/village_school.png`·`village_clinic.png`·`village_library.png` (2배 크기, 높이 140), 각 `_dark.png` (피해 때 꺼진 창만 담은 덧그림) |
| 만든 도구 | Leonardo.ai — 모델 Lucid Origin, **무료 플랜** (2026-11-16, 참가자가 직접 생성) |
| 원본 | `docs/licenses/원본_건물/학교·보건소·도서관_LeonardoAI.jpg` (1344×768). 소방서 원본은 시점이 달라 쓰지 않음 |
| 가공 | `tools/make_sprite.cjs`: 가장자리에서 이어진 흰 배경을 투명하게 → 벽 양옆의 나무·울타리·땅 줄 지움 → 처마 폭을 마을 칸 폭 + 8px에 맞춰 줄임(세로 1.15배) → 유리창만 어둡게 바꾼 덧그림 따로 저장 |
| 사용 위치 | 게임 화면 아래 줄의 학교·보건소·도서관 건물. 이름표·기분 얼굴·깃대·단장 장식·배지는 코드가 위에 그림. 파일이 없으면 예전 코드 그림으로 자동 대체 |

## 광장 바닥

| 가공 | `tools/crop_image.cjs`: 돌바닥과 원형 무늬만 잘라 냄(원형 무늬 가운데 = 조달청 가운데). 가운데 분수는 조달청에 가려 밑동만 비쳐서 지움 — 분수 그림자 쪽 고리는 위쪽 고리를 180도 돌려 덮고(`--mirror`), 분수 자리는 깨끗한 바닥 조각으로 덮음(`--patch`). 게임 안에서 연한 색을 덧칠 |

## 시험했다가 쓰지 않은 것
- `원본_건물/가구공방_LeonardoAI.jpg` (2026-11-16): 공방 칸(112×64)은 가격표·문·일꾼 창이 거의 다 덮어 그림을 바꿔도 지붕 색만 달라져서 쓰지 않음. 원본만 보관.

## 저작권·이용 조건
- 타이틀 배경과 같음(`타이틀배경_AI이미지_출처.md`): Leonardo.ai 무료 플랜 생성물은 상업적 이용 허락을 받지만 소유권은 Leonardo에 있고 공개 이미지로 취급됨. 유료 플랜은 생성물 소유권이 사용자에게 있음.
- 참가신청서 AI 활용 내역에 "Leonardo.ai 무료 플랜 – 배경 일러스트·건물 그림"을 적는다.
