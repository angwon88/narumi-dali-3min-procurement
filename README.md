# 나르미와 달이의 3분 조달작전

「2026 조달청 AI 게임·콘텐츠 공모전」 AI 게임 부문 출품작. 기획은 `기획서.md`.

## 실행
- 개발: `index.html`을 브라우저로 열기
- 제출용: `python3 tools/build.py` → `dist/index.html` (인터넷 없이 실행되는 파일 하나)

## 폴더
| 폴더 | 내용 |
|---|---|
| `js/` | 게임 코드 (순수 JavaScript + Canvas 2D) |
| `assets/` | 나르미·달이 스프라이트, 조달청 CI, Galmuri 글꼴 |
| `tools/` | 빌드 스크립트 |
| `docs/licenses/` | 출처·라이선스 |
| `공모전 첨부자료/` | 공모전 제공 원본 (수정 금지) |
| `제출물/` | 최종 제출 파일 (git 제외) |
