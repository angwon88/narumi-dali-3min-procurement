# 보관: 지금 게임에서 쓰지 않는 파일 (2026-11-18 정리)

게임·빌드·제출판에는 들어가지 않습니다. 지워도 게임은 그대로 돌아가지만, 기록용으로 남겨 둡니다.

| 폴더 | 내용 |
|---|---|
| `옛날그림_원본/` | 미래형으로 바꾸기 전 Leonardo.ai 그림 원본(옛날식 학교·보건소·도서관·소방서·광장·가구공방, 첫 미래 보건소), 예전 타이틀 배경(옛 마을 일러스트 원본·960px판), 쓰지 않은 조달청 꺼진 창 그림. 출처 기록은 `docs/licenses/`의 출처 문서 |
| `캐릭터데이터/` | 나르미·달이 픽셀아트 프레임 정보 JSON. 같은 내용이 `js/assets.js`의 `G.CHAR_META`에 들어 있어 게임은 이 파일을 읽지 않음 |
| `화면사진/` | 작업 중 Playwright로 찍은 확인용 화면(시험판 v8.0~v8.26). **git에는 올리지 않음**(이 컴퓨터에만 있음) |

쓰지 않는 코드(레벨업 카드·저금통·비축 등)는 설정으로 꺼 둔 채 `js/`에 그대로 있습니다. 파일을 빼면 게임이 깨지므로 옮기지 않았습니다.
